Welcome to Harness

Harness is an agentic workspace: you describe a task, and an agent reads, writes, and runs tools inside a project folder.

  • Projects are folders the agent may work in. A project can span several folders.
  • Conversations are knowledge-only chats with file and shell tools disabled.
  • Automations run the agent on a schedule.
  • Skills are reusable instructions the agent can follow or write for itself.

Add a model provider to start chatting. Nothing is configured by default.

Stored encrypted on disk. Leave blank for local providers.
